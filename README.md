# MostConnect — инструкция пользователя

**Скачать последнюю версию (Android):** [MostConnect.apk](https://github.com/ivankoval921-bit/mostconnect-releases/releases/latest/download/MostConnect.apk) · короткая ссылка: https://most-d2a27.web.app/apk
**Компьютер (без установки):** https://most-d2a27.web.app

## Что такое MostConnect
Защищённый мессенджер для своих: личные чаты, звонки, голосовые, фото и файлы. Всё шифруется на телефоне, ключ знают только участники чата.

## Главный экран
«Контакты и чаты» — список всех ваших людей. Нажмите на человека, чтобы открыть отдельный чат только с ним. Переписку и звонки в личном чате видите только вы двое.

## Добавить человека
1. «➕ Новый личный чат» → впишите имя (например, Костя).
2. «Отправить приглашение» → перешлите через WhatsApp, SMS или почту (или покажите QR-код).
3. Личное приглашение срабатывает только для одного человека и действует 24 часа. Пока он не вошёл, в списке будет «Костя — ждём ответа».

## Вас пригласили
1. Установите MostConnect по ссылке из приглашения.
2. Откройте ссылку входа или нажмите «Присоединиться по приглашению» → «Вставить» / «Сканировать QR».
3. Введите своё имя → «Присоединиться».

## Группа
«👥 Новая группа» — общий чат для нескольких человек: все участники видят всю переписку. Для личного разговора используйте личный чат.

## Звонок
В чате нажмите большую зелёную трубку справа. Звонок идёт только этому человеку.

## Фото и файлы
Скрепка → «Галерея»: отметьте сразу несколько фото и видео (до 50). «Документ» — любые файлы, тоже по несколько. Один файл — до 20 МБ.

## Голосовое сообщение
Держите микрофон и говорите, отпустите — проверьте и нажмите «Отправить». Свайп вверх — запись без рук.

## Галочки
Одна серая — отправлено, две серые — доставлено, две синие — прочитано. Синие появляются только когда человек открыл чат, а не просто увидел уведомление в шторке.

## Настройки телефона (один раз)
Меню ⋮ → «Звонки и уведомления»:
1. **Звонок на весь экран** — разрешить «Поверх других приложений».
2. **Уведомления** — разрешить (текст сообщений виден на заблокированном экране).
3. **Работа в фоне** — батарея «Без ограничений» (realme: «Дозволити активність у фоновому режимі»).

Samsung: Настройки → Уведомления → Уведомления на экране блокировки → «Карточки».

## Обновления
Когда выходит новая версия, приходит уведомление «Вышла версия…». Нажмите «Обновить» — программа обновится поверх, все чаты и разрешения сохраняются. Первый раз Android один раз спросит подтверждение, дальше обновление ставится само.

## Компьютер
Откройте ссылку приглашения в браузере на компьютере — чат и звонки работают без установки.
